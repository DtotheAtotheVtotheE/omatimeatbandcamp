Best explanation, in order of confidence:

1. **High confidence, measured.** The gap is not noise or double counting. Of the 687 Subsonic albums, 627 correspond one-to-one to web items, and every other difference is accounted for above.

4. **Pre-orders are invisible to Subsonic**: the one pre-order in the collection exists only in the web data, which is why web data must stay in the hybrid for pre-order display.

### API behaviour discovered while promoting the client

- `ping` with deliberately wrong credentials returns status `ok`, so Phase 0's "ping succeeded" showed the server is up, not that the credentials work. `getPlaylists` with the same wrong credentials: `getPlaylists: HTTP 500 (empty error body; the server does this for rejected credentials)`.
- `Client.check_auth()` therefore uses an authenticated call: real credentials -> True, wrong credentials -> False.
- Failures arrive as JSON, as XML (even with `f=json`), or as an empty HTTP 500; `parse_response` handles all three (covered in `tests/test_subsonic.py`).
